## ATIVIDADE 2.4 - VLSM COM 5 ROTEADORES
```bash
! Para as WANs utilizamos a sub-rede privada 10.0.0.0/30 para conectar os 5 roteadores linearmente (R1-R2, R2-R3, R3-R4, R4-R5).
! --- ROTEADOR R1 ---
enable
configure terminal
hostname R1
interface FastEthernet0/0
 ip address 165.214.32.1 255.255.255.192
 no shutdown
 exit
interface Serial0/0/0
 ip address 10.0.0.1 255.255.255.252
 no shutdown
 exit
ip route 0.0.0.0 0.0.0.0 10.0.0.2
end
write memory
```
