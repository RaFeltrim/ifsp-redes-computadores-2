# 📁 Tópico 2: Configuração de Rotas e Roteamento IP

## 📖 Visão Geral
Fundamentos de roteamento em Camada 3 (L3), tabelas de rotas no Cisco IOS, roteamento estático (rotas diretas e default route) e conceitos de protocolos de roteamento dinâmico (RIP, OSPF).

---

## 📋 Conteúdo Programático & Atividades Moodle
- [ ] Conceitos de Roteamento L3 e Tabela de Roteamento
- [ ] Configuração de Rotas Estáticas no Cisco Packet Tracer (`ip route`)
- [ ] Configuração de Rota Padrão (Default Route `0.0.0.0 0.0.0.0`)
- [ ] Diagnósticos com `show ip route`, `traceroute` e `ping`
