# 📁 Tópico 1: Revisão de Endereçamento IPv4 e Sub-redes

## 📖 Visão Geral
Estudo aprofundado do endereçamento IPv4, classes A a E, conversões binárias, NetID, Broadcast, máscaras de tamanho fixo (FLSM) e variável (VLSM), sumarização de rotas e práticas de laboratório no Cisco Packet Tracer.
