# 🗂️ Central de Prompts — Redes de Computadores 2 (IFSP)

Esta pasta contém o **Framework de Engenharia de Prompts** desenvolvido para automatizar, padronizar e garantir a máxima qualidade técnica nas entregas de laboratório, cálculos de sub-redes e geração de topologias na disciplina de **Redes de Computadores 2 (SCLRCO2)**.

## 🚀 Como Utilizar com Assistentes de IA (ChatGPT, Claude, Gemini, Cursor, Antigravity)

1. **Passo 1 (Cálculos):** Abra o arquivo [`01_resolucao_teorica_e_calculo_subredes.md`](01_resolucao_teorica_e_calculo_subredes.md), copie o prompt do sistema e cole o enunciado do exercício.
2. **Passo 2 (Topologias):** Utilize o prompt [`02_pipeline_geracao_topologias_packet_tracer.md`](02_pipeline_geracao_topologias_packet_tracer.md) para gerar os diagramas técnicos de rede com os IPs calculados.
3. **Passo 3 (Scripts IOS):** Utilize o prompt [`03_configuracao_cisco_ios_e_pkt.md`](03_configuracao_cisco_ios_e_pkt.md) para obter os blocos de configuração do roteador.
4. **Passo 4 (Relatório):** Use o prompt [`04_compilacao_relatorio_academico_pdf.md`](04_compilacao_relatorio_academico_pdf.md) para gerar o PDF oficial e o Markdown.
5. **Passo 5 (Auditoria):** Execute o checklist do prompt [`05_quality_assurance_e_matriz_validacao.md`](05_quality_assurance_e_matriz_validacao.md) para validação final.
