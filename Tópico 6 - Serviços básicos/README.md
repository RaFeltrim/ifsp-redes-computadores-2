# 📁 Tópico 6: Implementação de Serviços Básicos de Servidores

## 📖 Visão Geral
Instalação, configuração, hardening e manutenção de serviços corporativos em ambiente Linux real: Servidor DHCP (`isc-dhcp-server`), Servidor DNS (`bind9`), Servidor Web (`Apache2` / `Nginx`) e Servidor Proxy (`Squid`).

---

## 📋 Conteúdo Programático & Atividades Moodle
- [ ] Servidor DHCP no Linux (Configuração de escopos, concessões estáticas e opções)
- [ ] Servidor DNS com BIND9 (Zonas diretas, reversas e encaminhadores)
- [ ] Servidor Web Apache/Nginx (Virtual Hosts, permissões e portas)
- [ ] Servidor Proxy Squid (Controle de acesso, ACLs, autenticação e cache)
