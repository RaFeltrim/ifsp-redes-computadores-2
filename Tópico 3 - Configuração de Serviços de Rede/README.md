# 📁 Tópico 3: Configuração de Serviços de Rede no Simulador

## 📖 Visão Geral
Implementação e análise de serviços fundamentais da camada de aplicação (L7) e infraestrutura de suporte no Cisco Packet Tracer, incluindo servidores DHCP, DNS, HTTP/Web e Email.

## 📋 Conteúdo Programático & Atividades Moodle
- [ ] Servidor DHCP (Alocação dinâmica de IPs, Pool, Gateway e DNS)
- [ ] Servidor DNS (Resolução de nomes de domínio, registros A e CNAME)
- [ ] Servidor HTTP/HTTPS (Publicação de páginas web locais)
- [ ] Servidor de E-mail (Protocolos SMTP/POP3)
