# 📁 Tópico 5: Configurações Iniciais em Servidores Linux

## 📖 Visão Geral
Administração de sistemas Linux voltada a servidores de rede, gerenciamento de interfaces de rede via terminal (CLI), configuração estática e dinâmica de IPs (`/etc/network/interfaces` e `netplan`), roteamento e testes de conectividade.

---

## 📋 Conteúdo Programático & Atividades Moodle
- [ ] Comandos essenciais de rede Linux (`ip addr`, `ip route`, `ss`, `netstat`, `systemctl`)
- [ ] Configuração de interfaces estáticas com Netplan / ifupdown
- [ ] Configuração de servidores de nomes no `/etc/resolv.conf`
- [ ] Segurança básica e acesso remoto seguro via SSH (`sshd`)
